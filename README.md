# Sentiment Analysis Project

## Overview
This project predicts the sentiment of text (Positive/Negative) using Natural Language Processing. 

## Tech Stack
- Python
- Scikit-learn
- NLP (TF-IDF)
- Streamlit

## Features
- Text classification
- Real-time prediction
- Web app deployment

## How to Run Locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Train the model (generates `.pkl` files):
   ```bash
   python train_model.py
   ```
3. Run the web app:
   ```bash
   streamlit run app.py
   ```
